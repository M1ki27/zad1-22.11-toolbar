Co się stanie po zamianie app:showAsAction na android:showAsAction?
Ikona nie będzie poprawnie wyświetlana na pasku narzędzi. Pozycja menu trafi do menu ukrytego pod trzema kropkami. Poprawny zapis to app:showAsAction.


Dlaczego używamy return super.onOptionsItemSelected(item)?
Ta instrukcja przekazuje nieobsłużone kliknięcie do systemu i klasy nadrzędnej. Dzięki temu mogą działać standardowe funkcje, takie jak przycisk powrotu.
